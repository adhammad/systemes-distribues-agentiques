## Objectif

Créer une application basée sur une architecture micro-service qui permet de gérer les factures contenant des produits et appartenant à un client.

## Ressources

- Partie 1 : https://www.youtube.com/watch?v=kOVHzN8I8e8
- Partie 2 : https://www.youtube.com/watch?v=-iM3J_mgqlM

## Travail à faire

1. Créer le micro-service customer-service qui permet de gérer les clients
2. Créer le micro-service inventory-service qui permet de gérer les produits
3. Créer la Gateway Spring Cloud Gateway
4. Configuration statique du système de routage
5. Créer l'annuaire Eureka Discovery Service
6. Faire une configuration dynamique des routes de la gateway
7. Créer le service de facturation Billing-Service en utilisant Open Feign
8. Créer le service de configuration
   - https://www.youtube.com/watch?v=-G2rcLMO1gQ
   - Repo GitHub : https://github.com/mohamedYoussfi/micro-services-app
9. Rendre cette architecture agentique en créant un agent AI conversationnel connecté aux micro-services via MCP, en s'inspirant de l'exemple traité en classe https://www.youtube.com/watch?v=YAS0wduB8bM et de l'exemple du projet
10. Créer des clients Discord et Telegram pour l'agent AI conversationnel
11. Créer un client Angular
